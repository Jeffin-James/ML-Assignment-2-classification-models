# Breast Cancer Classification — ML Assignment 2

## a. Problem Statement
Build, evaluate, and deploy multiple supervised classification models that predict
whether a breast tumour is **malignant** or **benign** from digitized fine needle
aspirate (FNA) image measurements. The goal is to compare five classical ML
algorithms on the same dataset using standard classification metrics, and to expose
the trained models through an interactive Streamlit web app for evaluation on
held-out test data — without retraining in the app.

## b. Dataset Description
- **Name:** Breast Cancer Wisconsin (Diagnostic) Data Set
- **Source:** UCI Machine Learning Repository (also bundled with scikit-learn,
  `sklearn.datasets.load_breast_cancer`, which mirrors the original UCI data)
- **Task type:** Binary classification (`malignant` vs. `benign`)
- **Instances:** 569
- **Features:** 30 numeric features (mean, standard error, and "worst" value of 10
  real-valued measurements computed from each cell nucleus image, e.g. radius,
  texture, perimeter, area, smoothness, compactness, concavity, concave points,
  symmetry, fractal dimension)
- **Target column:** `target` (0 = malignant, 1 = benign)
- **Train/Test split:** 80% train (455 rows) / 20% test (114 rows), stratified on
  the target. The test split is saved as [test_data.csv](test_data.csv) and is the
  file used to demo the Streamlit app.

## d. Models Used

All five models were trained on the same 80% stratified train split (features
standardized with `StandardScaler` fit only on the training data) and evaluated on
the same held-out 20% test split.

### Observations

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Excellent performance (98.25% accuracy, AUC 0.9954). The dataset's classes are close to linearly separable after standardization, so a linear decision boundary fits very well and generalizes cleanly to the test set. |
| Decision Tree | Weakest of the five (92.11% accuracy, AUC 0.9163). A single tree with limited depth overfits to axis-aligned splits on the training data and loses some recall on malignant cases, so it generalizes worse than the other models on this dataset. |
| KNN | Strong performance (97.37% accuracy, perfect recall 1.0000). Because features are standardized, distance-based neighbor voting works well; it catches every malignant case in the test set, though precision is slightly lower (a few extra false positives). |
| Naive Bayes | Good but not top-tier (92.98% accuracy, AUC 0.9868 despite lower accuracy). Gaussian Naive Bayes assumes feature independence, which does not fully hold for correlated cell-measurement features, slightly hurting precision/recall, even though its ranking ability (AUC) stays high. |
| Support Vector Machine | Best/tied-best performer (98.25% accuracy, AUC 0.9950) with an RBF kernel. It finds a wide-margin boundary in the scaled feature space, matching Logistic Regression's accuracy and MCC almost exactly. |
| **Overall, Winner for your dataset?** | **Logistic Regression and SVM are tied for the best overall performance** (highest Accuracy, F1, and MCC), with Logistic Regression having a marginally higher AUC. Given its simplicity and interpretability alongside top-tier metrics, **Logistic Regression** is the practical winner for this dataset. |

## How to Run Locally
```bash
pip install -r requirements.txt
python train_models.py   # regenerates model/ artifacts and test_data.csv
streamlit run app.py
```

## Streamlit App Features
- Upload a test CSV (e.g. `test_data.csv`) containing the 30 feature columns plus
  the `target` column.
- Select which trained model to use via a dropdown (Logistic Regression, Decision
  Tree, KNN, Naive Bayes, SVM).
- View Accuracy, AUC, Precision, Recall, F1, and MCC for the selected model on the
  uploaded data.
- View the confusion matrix (heatmap) and full classification report.
- Optional: compare all 5 models side-by-side on the same uploaded data.

The app only loads the pre-trained model and scaler saved under `model/` — it never
retrains on the uploaded data.
